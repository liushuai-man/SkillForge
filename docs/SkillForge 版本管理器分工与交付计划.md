# 第一块 · 开发者 A（存储内核线）

> **一句话职责**：把"改一下文件"变成"一个可寻址的快照"，并提供接口与命令行。

## 一、你负责的模块

| 模块 | 名称 | 你要做的事 |
| --- | --- | --- |
| M-01 | 工作区管理 | 绑定 Skill 目录，读写 `workspace.json`（忽略规则、文件类型到解析器的映射） |
| M-02 | 改动监听与快照 | 监听文件保存、500 毫秒合并抖动、内容哈希二次确认、触发快照 |
| M-03 | 对象库与去重 | SHA-256 内容寻址的 blob/tree/meta，原文保真、zlib、完整性；回收后续做 |
| M-04 | 修订与引用 | Revision / Change / Ref 元数据，稳定的 Change ID，revset 表达式解析 |
| M-09 | 操作日志与撤销 | 操作日志记录；恢复 v1 为指定修订 `restore` 与最近恢复的 `undo`（含撤销撤销），见实现契约 §2.4 |
| M-10 | 接口层 | HTTP 路由、参数校验、统一返回 `{ ok, data, error, request_id }`、事件流 |
| M-12 | 命令行客户端 | `start / init / status / snapshot / diff / log / tag / restore / undo / show`；业务命令只调服务 |

## 二、每周要做什么

### 第 1 周｜10 月 4 日 – 10 月 10 日（地基）
- **做**：M-01 工作区纳管；M-03 内容寻址/压缩/两级目录与读回校验；核对现有 DDL；准备公开模型与 B 消费样例。
- **交**：能绑定目录并读回首个对象；初始化失败可重试；对象损坏可识别；完成 G0 中 A 的交接与 TBD-09 方案。
- **验**：AC-01~03、AC-16；已有 DDL 不等于修订/撤销逻辑已经实现。

### 第 2 周｜10 月 11 日 – 10 月 17 日（快照闭环）
- **做**：M-02 监听/静默合并/稳定扫描；M-04 修订、Change 分组与最小 ref 解析；串行提交；落实已关闭的 TBD-09。
- **交**：有限保存突发只提交最终稳定内容；原文不变 0 次业务写盘；A→B→A 记录三次事件且复用内容；提供 B 可读取的真实 Revision 对。
- **验**：AC-04~09、AC-15 的快照故障点；达到 G1。

### 第 3 周｜10 月 18 日 – 10 月 24 日（对比闭环）
- **做**：M-10 真实接口/统一错误/提交后事件；M-12 客户端；M-09 Op/undo；用户打标后选择 Baseline；与 B 联调真实默认报告。
- **交**：默认 diff 输出规范语义报告 JSON；无基线正确回退；锚点与撤销符合已关闭 TBD-08/09 的状态样例。
- **验**：AC-08/09/17/18；不得用文件恢复未定或接口占位宣称 G2 通过。

### 第 4 周｜10 月 25 日 – 11 月 1 日（打磨与交付验收）
- **做**：故障恢复与跨平台边界；端口发现/进程占用；发布包集成预构建前端；安装说明；容量和性能测量。gc/CDC 不在本周补做。
- **交**：可安装包 + 可复现的安装步骤 + 验收记录，明确已测与未测平台；达到 G3。
- **验**：AC-15~20，覆盖断网与终端用户无 Node；不以本机 npm 构建成功代替安装包验证。

2026-10-13 用户批准恢复 v1：本轮 A 线实现整个 Skill 恢复到指定修订与撤销最近一次恢复，先预览确认，按实现契约 §2.4 验证 AC-18。TBD-08 已关闭、TBD-09 恢复子协议冻结；Baseline/完整报告闭环仍未完成，不将本轮范围等同 G2。

## 三、你的验收标准

| 项 | 标准 |
| --- | --- |
| 变更合并 | 有限突发后 500 ms 静默，只提交最终稳定快照；Change 分组另按设计 §7.2 |
| 零写入 | 原始 tree 与当前已提交状态相同：0 新对象/Revision/Op/业务数据库更新 |
| 快照速度 | 保存后 ≤ 2 秒可见"有未纳管改动"；写入（≤ 1 MB）≤ 300 毫秒 |
| 撤销 | TBD-08/09 关闭后的状态样例通过，含撤销撤销；不能以版本库指针变化冒充文件恢复 |
| 存储 | 10000 次保存按唯一对象累计压缩大小测量，无重复对象；变化大文件的完整 blob 写放大单列 |
| 平台 | Windows / macOS / Linux 行为一致 |
| 总验收 | 改一次 Skill → 不做任何版本操作 → 看到对比报告 → 可打锚点 → 可撤销 |
