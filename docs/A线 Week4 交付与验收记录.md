该模式复用现有依赖，不等同干净机器安装、pipx 安装或物理断网环境验证。

终端用户安装方式：`pipx install <wheel路径>`；运行 `skillforge-vm --data-root <数据目录> start`，业务命令传相同全局数据根或统一设置 `SKILLFORGE_VM_DATA_ROOT`。

## 容量与性能实测

脚本：`scripts/benchmark_storage.py`；原始证据：[A线性能实测.json](./A线性能实测.json)。

样例在 C 盘临时目录运行；物理介质型号未识别、实际文件分配空间未测。
同进程运行，OS 缓存未清空，无报告缓存。固定随机种子 20261013。
本次測量覆盖小文件 10,000 次保存与 30 次 1 MiB 唯一完整 blob；**不代表 5 MiB 文本 + 200 MiB 资源的完整容量上限验收**。

| 样例 | 次数 | p50 | p95 |
| --- | ---: | ---: | ---: |
| 1 KiB 不变捕获 | 3334 | 30.957 ms | 50.616 ms |
| 1 KiB 历史内容保存 | 3333 | 15.592 ms | 42.152 ms |
| 1 KiB 唯一内容保存 | 3333 | 45.032 ms | 84.328 ms |
| 1 MiB 唯一内容完整捕获（含扫描） | 30 | 39.900 ms | 51.481 ms |
| 1 MiB 只读状态扫描/哈希 | 30 | 23.132 ms | 41.666 ms |

10,000 次保存：不变组新增修订 0；历史组 3332（首个历史输入与初始相同）；唯一组 3333。
含初始化共 6666 个修订、13336 个唯一对象（与索引数量一致）；累计压缩对象 2,509,115 bytes，SQLite 10,956,800 bytes。
后续 30 次 1 MiB 唯一随机内容使压缩对象增长 31,480,013 bytes，符合完整 blob 写放大，不是按变更行增量存储。
完整捕获计时比纯写入更宽，本样例 p95 低于 300 ms；扫描/哈希样例低于 200 ms。不是全平台性能承诺。
